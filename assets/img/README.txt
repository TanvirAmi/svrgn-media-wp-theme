Images referenced by the theme that you'll want to replace with real uploads:

- assets/img/placeholder-team-1.jpg, placeholder-team-2.jpg, placeholder-team-3.jpg
  Used as fallback team photos on the About page (about-team widget area default).
  Easiest fix: once you add real team photos via Media Library, either replace
  these files directly, or add a Custom HTML widget to the "About — Team"
  widget area with your own <img> tags.

- assets/img/slider-1.png
  The decorative background "planet" graphic on the Contact page hero.
  Upload your own and keep the same filename, or edit the src in page-contact.php.

Everything else (case studies, services, project thumbnails) uses the WordPress
Featured Image, so just set a featured image per post/page — no manual file
uploads needed there.
